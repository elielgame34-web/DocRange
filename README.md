# DocRange
Scanner → lecture du texte → classement automatique → recherche → export PDF.
Tout reste sur le téléphone (aucune clé API, aucun serveur).

## Compiler l'APK
1. Crée un dépôt GitHub et pousse ce dossier sur `main`.
2. Onglet Actions → « Build DocRange APK » → télécharge l'artefact `app-debug.apk`.
